Ziel: alle Karten nach Farbe von Ass bis König auf die vier Ablagen oben rechts. In den Spalten abwechselnd rot und schwarz absteigend anlegen; auf leere Spalten nur Könige. Eine Karte antippen legt sie automatisch an die beste Stelle. Geht das nicht, wird sie markiert – dann das Ziel antippen. „Ablegen“ bringt alle passenden Karten auf die Ablagen. Das Spiel wird gespeichert.
